# Клуб серфинга «Волна»

Веб-приложение для клуба серфинга и обучения серфингу.  
Курсовая работа по МДК 08.01 «Проектирование и разработка интерфейсов пользователя»

## Стек

- **Frontend:** HTML5, CSS3, JavaScript
- **Backend:** PHP (PDO)
- **БД:** MySQL (phpMyAdmin)

## Возможности

- Главная страница со слайдером (автопереключение 3 сек)
- Каталог форматов обучения (из БД)
- Регистрация / авторизация с валидацией
- Заявка на обучение (формат, дата, оплата)
- Личный кабинет — история заявок и статусы
- Отзывы — просмотр и добавление (сохранение в MySQL)
- Панель администратора — фильтры, смена статусов заявок
- Адаптивный голубо-зелёный дизайн

## Установка (XAMPP / OpenServer)

1. Скопируйте содержимое репозитория в `htdocs/surfclub` (или `domains/surfclub`)
2. Запустите Apache и MySQL
3. В phpMyAdmin импортируйте файл `sql/schema.sql`
4. При необходимости отредактируйте `config.php` (логин/пароль MySQL)
5. Откройте: http://localhost/surfclub/
